# jichi Desktop

Настольный клиент для [агента jichi](https://github.com/alexanderlarsdallmann/jichi).
Запускает локальный бинарник через Tauri и общается с ним по ACP. Интерфейс
на React + TypeScript; процесс, файлы и секрет обслуживает Rust.

**Новому участнику:** начни с [актуального описания проекта](docs/PROJECT_HANDOFF.md).
Там записаны замысел пользователя, структура кода, визуальные ориентиры,
ссылки, команды и известные ограничения. Старый
`docs/AUFTRAG_OBERFLAECHE.md` оставлен как история прежней ветки и не является
текущим заданием.

## Локальный запуск

```sh
npm install
npm run tauri dev
```

Vite использует порт 1420. Для взаимодействия с агентом нужен Tauri window:
обычная вкладка браузера не имеет доступа к Tauri bridge.

## Проверка

```sh
npm run check
npm run check:rust
npm run build
```

Приложение ещё находится в разработке. У этого локального репозитория на

к исходникам desktop-клиента.
