# Боковая панель — план и решения

Актуально на 25.09.2026. Что умеют похожие продукты, что из этого делаем мы
и почему именно так.

## 1. Что есть у других

| Продукт | Что открывается справа | Характерное |
| --- | --- | --- |
| **Claude — Artifacts** | HTML/CSS/JS, React, SVG, Mermaid, Markdown, документы | вкладки **Vorschau / Code**, живой запуск, копировать, скачать, версии |
| **ChatGPT — Canvas** | документ или код в редакторе | правка на месте, **выделить фрагмент → попросить изменить**, история версий |

## 2. Что делаем в jichi Desktop

Одна **боковая панель** справа от чата: вкладки, ширина меняется
перетаскиванием, можно развернуть на всё окно. В ней шесть видов окон:

| Окно | Что показывает | Откуда открывается |
| --- | --- | --- |
| **Dateien** | дерево проекта | кнопка в шапке, ⌘⇧E |
| **Datei** | просмотр любого файла: код с подсветкой и номерами строк, Markdown (Vorschau/Quelltext), картинки, PDF (pdf.js), Word (как документ), Excel/CSV (таблица по листам), HTML (→ Browser); **правка и сохранение** для текста с проверкой конфликта; **«Auswahl an jichi»** — выделение уходит в поле ввода | дерево, карточка файла, путь в ответе |
| **Änderungen** | незакоммиченные изменения (git): список файлов и diff; **комментарий к строке** → «Kommentare senden» пишет jichi, что исправить; «Code prüfen lassen» | ⌘⇧D, карточка правки |
| **Terminal** | настоящий терминал (PTY) в папке проекта, несколько вкладок; вкладка **jichi** — живые команды агента | Ctrl+\`, карточка команды |
| **Browser** | настоящий встроенный браузер (дочерний webview): dev-сервер, документация, адресная строка, назад/вперёд/обновить | ⌘⇧B, ссылка в ответе |
| **Artefakt** | блок кода из ответа (HTML, SVG, Mermaid, Markdown) — **Vorschau / Code**, копировать, сохранить в проект | кнопка у блока кода |

## 3. Безопасность — это не украшение

- **Файлы** читаются и пишутся только внутри открытого проекта; проверяет Rust.
- **Artefakte** и HTML из проекта работают в `iframe sandbox="allow-scripts"` без
  `allow-same-origin` — они не видят приложение, ключ и Tauri.
- **Браузер** — отдельный webview без доступа к командам приложения (IPC для
  внешних адресов в Tauri закрыт).
- **Терминал** — ваш shell, в папке проекта, без переменных с ключами.
- «Öffnen» во внешней программе — только документы и картинки.

## 4. Этапы

1. Каркас панели + Dateien + Datei (текст, код, Markdown, картинки).
2. PDF, Word, Excel; карточки и пути в чате открывают панель; правка и сохранение.
3. Änderungen (git diff, комментарии к строкам).
4. Terminal (PTY + xterm.js) и вкладка команд jichi.
5. Browser (дочерний webview).
6. Artefakte из блоков кода; «Auswahl an jichi».
